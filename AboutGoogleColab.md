# Краткая инструкция по работе с Google Colab

**Google Colab** - это бесплатная облачная среда для работы с блокнотами Jupyter
Notebook, которая позволяет выполнять код на языке Python в браузере. Она
предоставляет доступ к мощным вычислительным ресурсам, включая GPU и TPU, и
позволяет работать с большими объемами данных. Рабочее пространство
"сбрасывается" каждые 12 часов.

Файлы, с которыми работает Google Colab имеют расширение `.ipynb` и являются
Jupyter Notebook. Такие файлы можно создавать и запускать и в других средах
разработки, такие как [Jupyter](https://jupyter.org/), [Visual Studio
Code](https://code.visualstudio.com/),
[PyCharm](https://www.jetbrains.com/pycharm/).

## Создание и загрузка блокнотов Google Colab

### Создать новый блокнот Google Colab и начать работу

1. Откройте [Google Colab](https://colab.research.google.com/)
2. Нажмите на кнопку `+ Создать блокнот`
3. В ячейку добавьте код или добавьте ячейку `+ Текст` для markdown текста

### Открытие готового блокнота и работа с ним

1. Откройте [Google Colab](https://colab.research.google.com/)
   1. Выберете `Загрузить` если хотите загрузить блокнот с вашего ПК, далее
      будет открыто модальное окно загрузки файла.
   2. Выберете `Google Drive` если хотите загрузить блокнот с вашего Google
      Drive, далее в окне будут доступные файлы.

## Как работать с блокнотом в Google Colab

- Типы ячеек:
  - **Code** (по умолчанию) — для написания кода.
  - **Markdown** — для текста, формул (LaTeX) и изображений.
- Чтобы добавить ячейку наведите курсор между ячейками → нажмите `+` с выбранным типом.
- Чтобы удалить ячейку выберите ячейку → `Правка` → `Удалить ячейку`.
- Используйте `!` для shell-команд: `!pip install pandas`
- Чтобы запустить код, описанный в ячейке используйте `Shift + Enter` или кнопка
  ▶.
- Ядро поддерживает состояние вычислений notebook. Это значит, что значение,
полученное в ходе запуска ячейки хранится и может быть использовано при
вычислении кода в следующей ячейке. Вы можете сбросить это состояние,
перезапустив ядро.
- Для больших вычислений закрывайте вкладку браузера - сессия продолжит работу
- Бесплатная версия имеет ограничения: 12 часов непрерывной работы, ОЗУ до 25GB
- Если вы хотите клонировать репозиторий git, то вставьте следующий код в первую
  ячейку блокнота и выполните его:

```python
# Клонирование репозитория
!git clone https://github.com/...

# Установка необходимых пакетов
!pip install numpy pandas matplotlib scipy ...
```

**Пример Markdown**:
```markdown
# Заголовок
Текст с **жирным** шрифтом.
```

## Загрузка файлов для использования в блокнотах в Google Colab

Если необходимые файлы хранятся на локальном компьютере или Google Drive, то
нужно подгрузить их в так называемое «Сессионное хранилище» (session storage, по
сути, сервер Google). Слово «сессионное» указывает на то, что данные, как я уже
говорил, хранятся временно и после завершения очередной сессии стираются.

Подгрузить данные с локального компьютера можно двумя способами: Вручную, с
помощью UI или же командами Python.

### Загрузка файлов вручную через вкладку «Файлы»

1. На боковом меню слева выберите вкладку "Файлы".
2. В меню верхней панели выберете необходимый источник файлов локальное хранилище ПК или Google Drive.

### Загрузка файлов с помощью команд

#### Загрузка файлов c ПК

Чтобы загрузить файл с ПК, необходимо использовать функцию `upload()` из библиотеки `google.colab.files`.

```python
from google.colab import files
uploaded = files.upload()
```

#### Загрузка файлов c Google Drive

Чтобы загрузить файл из Google Drive, необходимо подключить Google Drive к Google Colab, используя функцию `drive.mount()`. Загрузить файл из Google Drive, используя функцию `open()`.

```python
# Подключение Google Drive
from google.colab import drive
drive.mount('/content/gdrive')

# Загружаем файл и выводим содержимое
with open('/content/gdrive/MyDrive/file.txt', 'r') as f:
  contents = f.read()
  print(contents)
```

## Сохранение результатов вычислений блокнота Google Colab в файлы

Полученные в результате исполнения кода файлы так же сохраняются в «Сессионное
хранилище». Выгрузить их можно так же двумя способами: Вручную, с помощью UI или
же командами Python.

### Сохранение файлов вручную через вкладку «Файлы»

1. На боковом меню слева выберите вкладку "Файлы".
2. Выберете нужный файл и кликните на значок "Меню".
3. Выберете пункт "Скачать".

Если у вас будет подключен Google Drive, то файлы будут сохранятся туда.

### Сохранение файлов с помощью команд

#### Сохранение файлов на ПК

Чтобы сохранить файл на ПК, необходимо использовать функцию `download()` из
библиотеки `google.colab.files`.

```python
from google.colab import files
files.download('результат.txt')
```

#### Сохранение файлов в Google Drive

Чтобы сохранить файл в Google Drive, необходимо подключить Google Drive к Google
Colab, используя функцию `drive.mount()` и сохранить файл в Google Drive,
используя функцию `open()`.

```python
# Подключение Google Drive
from google.colab import drive
drive.mount('/content/gdrive')
# Запись в файл
with open('/content/gdrive/MyDrive/file.txt', 'w') as f:
  f.write('Hello World!')
```

## Совместное использование

Google Colab позволяет совместно работать над блокнотами в режиме реального
времени. Вы можете открыть доступ к папке другим пользователям через интерфейс
Google Drive.

Чтобы пригласить других пользователей к работе над блокнотом, необходимо:

1. Нажать кнопку "Поделиться" в меню.
2. Ввести адреса электронной почты пользователей, которых необходимо пригласить.

## Скачивание и сохранение блокнота из Google Colab

1. Файл блокнота можно сохранить на Google Drive: `Файл -> Сохранить копию на
2. Автосохранение в Google Drive (если подключен) Google Drive`
3. Файл блокнота можно скачать на ПК: `Файл -> Скачать -> выбрать формат`

## Полезные функции

### Использование GPU

Google Colab предоставляет доступ к GPU, что позволяет ускорить выполнение кода.
Чтобы использовать GPU, необходимо выполнить: `Изменить -> Настройки блокнота ->
Ускоритель -> GPU`

### Предотвращение отключения сессии Google Colab

Google Colab отключает сессию после некоторого времени бездействия. Чтобы
предотвратить отключение сессии Google Colab, выполните скрипт:

   ```javascript
   // Выполните в JavaScript-консоли браузера
   function ClickConnect(){
     console.log("Clicking connect button");
     document.querySelector("colab-connect-button").click()
   }
   setInterval(ClickConnect, 60000)
   ```
