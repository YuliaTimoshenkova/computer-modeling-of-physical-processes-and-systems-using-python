# Компьютерное моделирование физических процессов и систем на языке Python

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.12+](https://badgen.net/badge/python/3.12+/blue)](https://www.python.org/downloads/)
[![Jupyter](https://badgen.net/badge/Jupyter/Notebooks/F37626)](https://jupyter.org/)

Репозиторий содержит примеры кода на Python к книге C. В. Поршнев, Н.Т. Сафиуллин, Ю. С. Тимошенкова «Компьютерное моделирование физических процессов на языке Python».

## 📖 О проекте

Цель данного репозитория — предоставить читателям актуальные инструменты для компьютерного моделирования физических процессов и систем с понятными примерами и подходами к решению задач.

> **Внимание:** Данный репозиторий содержит только программный код и его базовые описания. Полный теоретический разбор, выводы формул и методические указания читайте в новой книге.
>
Для того чтобы понимать примеры и было удобно с ними работать стоит ознакомится
с файлом в файле [`AboutPython.ipynb`](AboutPython.ipynb), в котором представлены
базовые понятия языка Python, используемые в книге.

## 🚀 Быстрый старт

Все примеры файлах `*.ipynb`, это формат тетрадок, в
которых можно писать блоки кода и текста и запускать их.

Прежде всего, [Jupyter Notebook](https://jupyter.org/) - это интерактивная среда
для написания и запуска кода.

Для работы с файлами можно использовать [Jupyter](https://jupyter.org/), [Visual Studio
Code](https://code.visualstudio.com/), [PyCharm](https://www.jetbrains.com/pycharm/) и
сервис от [Google Colab](https://colab.research.google.com/) для работы с
Jupyter Notebook. Имеет возможность использования библиотеки TensorFlow для
обучения нейронных сетей.

### Клонирование репозитория

#### Google Colab

Инструкция по работе с [Google Colab](https://colab.research.google.com/)
представлена в файле [`AboutGoogleColab.md`](AboutGoogleColab.md). Для
клонирования репозитория выполнить:

```python
# Клонирование репозитория
!git clone https://github.com/...
```

#### На личном ПК

```bash
git clone https://github.com/[ваш_логин]/porshnev-physics-simulations-python.git
cd porshnev-physics-simulations-python
```

Для полноценной работы так же придется создать или настроить виртуальное окружение

```bash
# Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Windows (cmd)
python -m venv venv
venv\Scripts\activate
```

Установить зависимости, используемые в файлах

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Все примеры оформлены в виде **Jupyter Notebooks** — это позволяет интерактивно изучать код, формулы и графики.

```bash
jupyter notebook
```

## 📂 Структура репозитория

Структура папок повторяет главы книги:

```
.
├── requirements.txt             # Зависимости Python
├── ipynbFiles/                  # Все файлы формата *.ipynb с примерами из книги для быстрого запуска, распределены по главам│
├── pyFiles/                     # Все файлы формата *.py с примерами из книги, распределены по главам
├── AboutGoogleColab.md         # Файл с инструкцией как использовать Google Colab
└── AboutPython.ipynb           # Файл с базовой информацией о языке Python, которая используется в книге
```
